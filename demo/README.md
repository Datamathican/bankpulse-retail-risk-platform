# Prebuilt demo outputs

These small sample outputs are generated by the actual BankPulse code using **250 synthetic customers**, **16 months** and RNG seed **42**. They are provided for inspection before a fresh local run; they are **not** the default 1,200-customer / 30-month output.

- `sample_dashboard.html`: double-click to open offline; figures and values correspond to the prebuilt sample.
- `model_metrics_sample.json`: machine-readable holdout validation and model selection results.
- `model_card_sample.md`: fully generated model card documenting the data split and limitations.
- `data_quality_sample.json`: executed source rules and quarantined error counts.
- `portfolio_monthly_sample.csv`: month-end analytical mart output for a quick review.

The HTML embeds Plotly's JavaScript and will work without a server or internet. The CSV and model metrics are demo data and do not constitute actual bank intelligence.
